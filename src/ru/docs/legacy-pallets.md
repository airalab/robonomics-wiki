В рантайме остались пять паллетов из прошлых версий Robonomics: Datalog, Launch, RWS, DigitalTwin и Liability. [README ноды](https://github.com/airalab/robonomics#readme) помечает их как устаревшие: «following pallets will be removed in near future». Дата удаления не объявлена.

Сегодня они работают в сети, и их используют некоторые приложения и интеграции. Новые проекты лучше начинать с [дерева устройств](/docs/device-tree/).

| Паллет | Что делает | Замена |
|---|---|---|
| Datalog | Хранит короткие записи под вашим аккаунтом | Дерево устройств; хранилище 5.0 запланировано |
| Launch | Отправляет подписанную команду на аккаунт устройства | — |
| RWS | Подписки на транзакции без комиссии | Подписки 5.0 (в разработке) |
| DigitalTwin | Связывает топики цифрового двойника с аккаунтами | Дерево устройств |
| Liability | Соглашения между сторонами с отчётом в конце | — |

## Datalog

Datalog хранит в блокчейне короткие записи под вашим аккаунтом. Каждая запись получает метку времени.

- `record(record)` добавляет запись размером до 512 байт.
- `erase()` удаляет все ваши записи.
- Для каждого аккаунта хранятся **последние 127 записей**. Более старые перезаписываются. (В окне 128 слотов, и один всегда остаётся свободным.)
- Большие данные положите в IPFS, а в запись поместите CID.
- Читать можно запросами к хранилищу `datalog.datalogIndex(account)` — он возвращает первый и последний слот — и `datalog.datalogItem([account, slot])`. Событие — `NewRecord`.
- Депозита нет, только обычная комиссия. На момент написания полная запись в 512 байт стоит около 0.0006 XRT.
- С подпиской RWS запись можно отправить без комиссии, через `rws.call`.

Кто пользуется сейчас: Robonomics Report Service для Home Assistant, агенты sensors.social connectivity, графики Altruist и мониторинга энергии в robonomics.app.

Как сделать первую запись, описано в разделе [Начало работы](/docs/getting-started/#4-send-your-first-record).

## Launch

Launch отправляет устройству подписанную команду.

- `launch(robot, param)`: `robot` — аккаунт устройства, `param` — 32 байта. Обычно туда кладут дайджест CID из IPFS.
- Устройство следит за событиями `NewLaunch(sender, robot, param)` со своим адресом.
- Отправить launch на любой адрес может кто угодно. Устройство должно само проверять отправителя.
- Паллет также записывает `param` в одно глобальное значение `Goal`, которое перезаписывает каждый launch от любого отправителя. Опирайтесь на события, а не на это значение в хранилище.
- Комиссия примерно такая же, как за короткую запись datalog. С подпиской RWS команду можно отправить без комиссии.

robonomics.app использует Launch для управления Home Assistant, а старая обёртка для ROS 2 запускала через него роботов.

## Подписки RWS

RWS (Robonomics Web Services) даёт аккаунту транзакции без комиссии.

- Два вида: `Daily { days }` и `Lifetime { tps }`.
- Устройство из списка подписки отправляет вызовы через `rws.call(subscription_owner, call)` и не платит комиссию. Бесплатная пропускная способность накапливается со временем. Для подписки Daily она растёт на 10,000 µTPS, что равно 0.01 простого перевода в секунду.
- `set_devices(devices)` задаёт список из не более чем 32 аккаунтов устройств, которым разрешено пользоваться подпиской. Вызов заменяет весь список. Пользоваться `rws.call` может только устройство из списка.
- `transfer(target)` передаёт вашу подписку аккаунту, у которого подписки нет.

### Как получить подписку

- Подписки продаются на аукционе. `bid(index, amount)`: первая ставка должна быть больше 1 XRT. Ставки резервируются. Аукционы со ставкой закрываются каждые 10 блоков. Выигравшая ставка сжигается, а подписка регистрируется.
- Страница **Buy a subscription** в [robonomics.app](https://robonomics.app) одной транзакцией делает ставку на свободном аукционе и добавляет ваш аккаунт в список устройств. Нужен баланс больше цены плюс 0.01 XRT. Если свободного аукциона нет, приложение откажет.

### Текущее состояние

- Новые аукционы может запускать только Root. Sudo нет, поэтому для каждой новой партии аукционов нужен референдум в треке Root. Пока он не пройдёт, свободные аукционы могут закончиться.
- Подписки, которые выдаёт оракул (например, по токенам RWS в Ethereum — эксперименту 2021 года), не подключены: аккаунт оракула не задан. На странице токеномики сказано, что RWS подключат к рабочей сети после переноса балансов XRT из Kusama в Polkadot, сначала для некоммерческих проектов вроде sensors.social.
- Замена — Subscription из 5.0. С ней устройство сможет пользоваться сетью, не держа XRT само. Она в разработке, в рантайме её пока нет.

## DigitalTwin

Цифровой двойник — это список топиков, каждый из которых связан с аккаунтом-источником данных.

- `create()` создаёт двойника.
- `set_source(id, topic, source)` связывает 32-байтный топик с аккаунтом-источником.
- `remove_source(id)` удаляет источник.

Ему на смену пришло [дерево устройств](/docs/device-tree/).

## Liability

Liability фиксирует подписанные соглашения между сторонами.

- `create(agreement)` записывает подписанное соглашение. Его техническая часть ссылается на IPFS.
- `finalize(report)` закрывает соглашение отчётом.

В паллет также входит простой рынок таких соглашений. Замена не объявлена.
