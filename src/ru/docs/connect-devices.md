Подключить устройства к Robonomics можно двумя способами: через Home Assistant или напрямую, с любым устройством, которое умеет подписывать транзакции или общаться со шлюзом.

Готовое оборудование и установку умного дома предлагает Pinout Limited. Товары и услуги — на [pinout.cloud](https://pinout.cloud).

## Home Assistant

Для Home Assistant есть три интеграции. Они делают разное и поддерживаются в разной степени.

| Интеграция | Что делает | Состояние |
|---|---|---|
| [Robonomics Report Service](https://github.com/PinoutLTD/rrs-ha-integration) (Pinout) | Следит за проблемами в Home Assistant. Шифрует отчёт об ошибке, загружает его в IPFS и записывает CID в блокчейн. Отчёт превращается в заявку в поддержку у вашего интегратора. Раз в сутки также отправляет сигнал «я жив». | Поддерживается. Выходит в виде пре-релизов. Нужен Home Assistant 2026.3.1 или новее; устанавливается через HACS как пользовательский репозиторий. |
| [Robonomics integration](https://github.com/airalab/homeassistant-robonomics-integration) (airalab) | Удалённый доступ к Home Assistant через зашифрованные транзакции по подписке RWS, а также пользователи и резервные копии. | Не обновляется. Последний выпуск — 2.2.1 от октября 2025. Использует старый `robonomics-interface` 1.6.3, требует локальную ноду IPFS, а точки подключения по умолчанию всё ещё ведут в Kusama, которая остановлена. Можно выбрать точку подключения Polkadot. С текущим рантаймом не проверялась. |
| [Altruist integration](https://github.com/airalab/altruist-homeassistant-integration) (airalab) | Читает датчик Altruist по локальной сети. Блокчейн не использует. | Небольшая, только локальная. |

Интеграция Robonomics от airalab зависит от подписок RWS. Их текущее состояние описано в разделе [Устаревшие паллеты](/docs/legacy-pallets/#rws-subscriptions).

## Любое устройство

Из этих шагов складывается подключение вашего собственного устройства.

1. **Дайте устройству собственный аккаунт.** Ключ остаётся на устройстве.
2. **Оплачивайте его транзакции.** Либо переведите на аккаунт немного XRT (на момент написания запись datalog стоит долю тысячной XRT), либо добавьте его в подписку RWS через `rws.set_devices` (до 32 устройств) и отправляйте его транзакции через `rws.call`.
3. **Опишите установку в дереве устройств.** Создайте узел для объекта и узлы для его устройств. Привяжите аккаунт устройства к его узлу как идентичность узла. Если за устройство пишет шлюз, выдайте шлюзу `Write`. См. [Дерево устройств (CPS)](/docs/device-tree/).
4. **Записывайте данные.** Кладите текущее состояние в `payload` узла (до 8 КиБ) или пишите записи через `datalog.record` (до 512 байт, [устаревший паллет](/docs/legacy-pallets/#datalog)). Большие данные положите в IPFS и запишите их CID.
5. **Отправляйте команды, если нужно.** Устаревший вызов `launch` отправляет на аккаунт устройства событие с подписанной командой. См. [Launch](/docs/legacy-pallets/#launch).

Библиотеки для каждого шага: Python `robonomics-interface`, JavaScript `@polkadot/api` и Rust `libcps` с утилитой `cps`. См. [Клиентские библиотеки](/docs/client-libraries/).

### Шлюзы для маленьких устройств

Не каждое устройство может работать с блокчейном. Посередине встают эти открытые шлюзы:

- **edge** ([airalab/robins](https://github.com/airalab/robins)): принимает подписанные сообщения по HTTP и Meshtastic и передаёт их дальше по libp2p GossipSub.
- **mqtt-bridge** ([airalab/robins](https://github.com/airalab/robins)): превращает сообщения MQTT в обновления дерева устройств.
- **sensors-connectivity** ([airalab/sensors-connectivity](https://github.com/airalab/sensors-connectivity)): собирает подписанные измерения датчиков и передаёт их в IPFS pubsub и парачейн. Обслуживает датчики на [sensors.social](https://sensors.social).

Публичные ретрансляторы и их состояние — на [pubsub.robonomics.network](https://pubsub.robonomics.network).
